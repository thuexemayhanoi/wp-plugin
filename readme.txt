AI-assisted WordPress content drafts with queue, QA and provider API keys. Supports 1-100 titles, Excel/CSV input and output limits.

== Description ==

- Claude, Gemini, OpenAI official APIs.
- Quick campaign setup and bulk title importing.
- Default Draft status, Matrix with retries and action scheduler.
- Word targets 1,000-5,000 and configurable output-token cap (subject to chosen model).
- Detects some API billing/credit errors and rate-limit errors separately.

== Installation ==

1. Install release ZIP from Plugins > Add New > Upload Plugin.
2. Activate, then open AI Content Factory > Viết bài nhanh.
3. Configure provider API key and model ID.
4. Test 1-5 Draft posts before processing larger batches.
