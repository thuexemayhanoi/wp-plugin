# Qwen Local Writer — No Commercial AI API (Experimental Beta)

**Status: BETA SOURCE — DO NOT INSTALL ON PRODUCTION YET.**
New standalone WordPress plugin located in this repo at qwen-local-writer/.
The legacy Multi AI SEO Content Factory v1.2.0 remains intact on main and is **not silently removed or migrated**. Existing paid-provider jobs are neither activated nor called by this new plugin.

## Purpose
Use open-weights text-generation model **Qwen3-0.6B**, not the Qwen embedding model, to draft roughly **1,500 words in Vietnamese or English** using the administrator's own WebGPU-enabled browser. NO Claude/Gemini/OpenAI API keys, paid model billing or model inference on the WordPress PHP server.

- Model: https://huggingface.co/onnx-community/Qwen3-0.6B-ONNX
- Library: pinned temporary CDN import of @huggingface/transformers@4.3.1 (browser-only).
- Source/review: all model prompts and drafts are untrusted output; Qwen is weak and can hallucinate. No automatic publication.
- QA: deterministic technical score with a target of >=70/100. It checks length, H2, extra H1, placeholders, repeated long paragraphs and forbidden code. **It does NOT establish factual correctness, Google ranking potential, or originality**. The saved draft needs human review.

## Functional prototype
1. Install beta ZIP **on staging only**, activate Qwen Local Writer.
2. Open WP Admin → Qwen Local Writer and enter title, keyword, verified source facts, language and category.
3. Click "Tải Qwen". Requires HTTPS + WebGPU + sufficient device memory and internet to download model weights. Works only while the admin tab remains open.
4. Click "Viết nháp khoảng 1.500 từ". Qwen generates an outline, opening, H2 sections and conclusion in separate passes. The output may be shorter/longer or lower quality.
5. Inspect/edit the Markdown and click "Lưu bản nháp". An authenticated nonce-protected WordPress AJAX handler always creates a **draft**, never an auto-published post.
6. Read back the WordPress draft ID, QA score and edit link. No hidden cron or API fees.

## Limitations and blockers to stable release
- The Qwen **0.6B model may be too weak** for consistently coherent, accurate 1,500-word SEO articles; measure on real VI/EN prompts.
- Browser WebGPU support, particularly on iPhone and cloud browsers, is **not guaranteed**. The plugin does not pretend inference can run after the tab closes.
- Initial JS library code is loaded from a **third-party CDN in Admin**. Before production, bundle/vet/version-pin the library locally with integrity and supply-chain controls; verify model file integrity/licensing and sandbox/staging compatibility.
- Browser inference and live WordPress save have NOT yet been manually tested on the actual target site. CI syntax/smoke checks are not proof of end-to-end inference.
- No mass campaigns, background headless worker, XLSX ingest, translations, batch retry, model switch to 1.7B, professional editorial reviewing, or QA of source accuracy in this beta. Never describe them as complete.
- There is no secure proof that user-submitted Markdown was actually generated by Qwen; QA scores content, not model provenance.
- It is a separate plugin; legacy v1.2 API plugin/data are preserved. Deactivate old API jobs separately before a future intentional migration.

## Build and test
From repository root:
    php qwen-local-writer/tests/quality.php
    php -l qwen-local-writer/qwen-local-writer.php
    php -l qwen-local-writer/includes/class-quality.php
    node --check qwen-local-writer/assets/qwen-worker.js
    node --check qwen-local-writer/assets/local-writer.js
    python3 scripts/build_qwen.py

Output: dist/qwen-local-writer.zip. The archive must contain one qwen-local-writer/ plugin folder, not repo's legacy API plugin.

## Security boundary
Only users with WordPress edit_posts permission access the editor and AJAX route. Uses WP nonce, input size caps, server-side validation, escaped Markdown->HTML conversion, WordPress safe draft insert and source content preserved as post meta. No auto-publish, deletion, rewrite of other posts, or commercial inference call. This beta is not permission to deploy to production.
